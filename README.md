# ₿itcash 💰

Este é um projeto que foi feito durante atividades acadêmicas para o centro universitário FIAP. Nesta atividade, eu botei em prática conhecimentos que eu obtive sobre design responsivo, Bootstrap, CSS e HTML. 

Ele foi baseado em um protótipo desenvolvido no Figma para o projeto Fintech, que consiste em nós, alunos, desenvolver a nossa fintech do zero.  

A tela que foi feita trata-se de uma landing page demonstrando a ideia da minha proposta, a qual tem a intenção de ser um lugar onde os clientes possam consultar seus Bitcoins e todas as suas outras finanças por um único canal, simples e intuitivo.

# Tecnologias usadas

- HTML
- CSS
- Bootstrap
- Design responsivo
- Git
